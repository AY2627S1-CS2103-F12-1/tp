# TutorFlow v1.3 — MVP

TutorFlow's first working release adapts AddressBook-Level3 (AB3) into a keyboard-friendly desktop manager for private tutors. It brings student and guardian contacts, homework and recurring weekly lessons into one local application.

## What's new compared with AB3

* **Student roster:** Add students with their academic level, tuition subjects, student phone number and guardian contact details. Use `list` (or `ls`) to view numbered student cards and `delete INDEX` to remove a student together with their homework and lessons. Required fields, phone numbers and duplicate students are validated.
* **Homework management:** Add, list and delete homework for individual students using `homework` or its `hw` alias. Records include a title, tuition subject and due date. Full dates and month/day input are supported; short dates report the inferred year. Duplicate homework and subjects a student does not take are rejected. Student cards show the number of assigned homework records.
* **Regular lessons:** Use `lesson add INDEX s/SUBJECT d/DAY st/START_TIME et/END_TIME` to create a weekly lesson. TutorFlow validates weekdays, 24-hour times and the student's subjects, and rejects duplicate or overlapping lessons across the tutor's schedule. Adjacent lessons are allowed. `lesson list` displays all students' lessons from Monday to Sunday, then by start time.
* **Automatic local saving:** Students, homework and lessons are saved to readable `data/tutorflow.json` and restored on restart. Failed saves undo the attempted change and report an error. Files are written through a temporary file to avoid partial writes; older student files without lessons remain supported.
* **Help inside the app:** `help` or F1 opens a command reference with formats, descriptions and examples. Scroll with the keyboard and press Escape to return to the command box.
* **Tutor-focused interface:** AB3's general contact roster is replaced by student cards with academic levels, subjects, guardian contacts and homework counts. Text wraps in the command feedback and cards. The guides and product website describe TutorFlow, and unused AB3 components and resources have been removed.

## Getting started

1. Install Java 25 or later. macOS users should follow the Java installation instructions in the [User Guide](https://ay2627s1-cs2103-f12-1.github.io/tp/UserGuide.html#quick-start).
2. Download `addressbook.jar` from this release and place it in a folder of your choice.
3. Open a terminal in that folder and run `java -jar addressbook.jar`.
4. Start with `list`, `hw list 1`, `lesson list` or `help`. A fresh installation includes sample data.

See the [User Guide](https://ay2627s1-cs2103-f12-1.github.io/tp/UserGuide.html) for examples and data-file rules. Back up `data/tutorflow.json` before deleting students, using `clear`, or editing the file manually; deletions cannot be undone.

## Current limitations

* This release supports adding and listing regular lessons. Individual lesson deletion is awaiting a separate increment.
* Homework editing, status changes and score recording are not available as commands. Homework listing includes completed records but does not display their status.
* A lowercase word followed immediately by a slash in a homework title is treated as a prefix. Use spaces around the slash, such as `km / h`.
* General AB3 contact commands such as `find` and `edit` are no longer supported. Existing AB3 contact files are not migrated into student records.
