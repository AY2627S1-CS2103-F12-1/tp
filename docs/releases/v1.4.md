## What's new since v1.3

* **Find students faster:** `search KEYWORD` matches part of a student or guardian name or phone number, ignoring case for names. Results show the search term and keep usable student indices. Run `list` to restore the full roster. [#74](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/74)
* **Edit student details:** `edit INDEX` updates selected profile fields without removing that student's homework or lessons. Duplicate identities and changes that would leave linked records with an invalid subject are rejected. Successful edits are saved; failed saves restore the earlier student. [#81](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/81)
* **Filter and sort the roster:** `filter [l/LEVEL] [s/SUBJECT]` narrows students by academic level and subject. `sort by/KEY [o/ORDER]` orders the displayed students by level, subject or regular meeting day. Neither command changes the saved roster order. [#79](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/79), [#80](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/80)
* **Update homework and record marks:** Edit a homework title, subject or due date with `hw edit`, and record or clear marks with `hw marks`. `hw list` shows upcoming homework with its marks; add `all` to include overdue records. The original homework index remains usable for further changes. [#68](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/68)
* **See upcoming homework across students:** `hw upcoming [due/DAYS]` lists work due from today through the chosen number of days (seven by default), ordered by due date. Results include each student's index so you can inspect their homework. [#69](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/69)
* **Use quoted values in prefixed commands:** Wrap a value in double quotes when it contains prefix-like text, such as `t/"Speed in km/h"`. The command keeps the text inside the quotes instead of treating `km/` as another prefix. [#73](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/73)

The Developer Guide now includes UML diagrams for student list, search, delete, add, filter and sort flows. [#83](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/83), [#85](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/85)

## Getting started

1. Install Java 25. On macOS, follow the [User Guide's Java setup instructions](https://ay2627s1-cs2103-f12-1.github.io/tp/UserGuide.html#quick-start).
2. Download `addressbook.jar` from this release and place it in a folder of your choice.
3. Open a terminal in that folder and run `java -jar "addressbook.jar"`.
4. Type `help` for the full command reference.

Data is saved locally in `data/tutorflow.json`. Back it up before deleting students or editing the file manually.
