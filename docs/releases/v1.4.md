# TutorFlow v1.4 — Alpha release

TutorFlow v1.4 expands the [v1.3 MVP](https://github.com/AY2627S1-CS2103-F12-1/tp/releases/tag/v1.3) with student discovery and editing, fuller homework and lesson workflows, and an at-a-glance view of the tutor's schedule. This is an alpha release, with further polishing planned for the next iteration.

## What's new since v1.3

* **Search, filter and sort students:** `search KEYWORD` finds partial matches in student or guardian names and phone numbers. `filter l/LEVEL s/SUBJECT` narrows the roster; either prefix may be omitted. `sort by/KEY [o/ORDER]` orders displayed students by level, subject or meeting day without changing their saved order. Run `list` to restore the full roster. [#74](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/74), [#79](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/79), [#80](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/80)
* **Edit student details:** `edit INDEX` changes selected profile fields while retaining that student's homework and lessons. Invalid changes, including subject changes that would invalidate linked records, are rejected. Edits are saved automatically and undone if saving fails. [#81](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/81)
* **Manage homework in more detail:** `hw edit` changes a title, subject or due date; `hw m` records or clears marks; `hw status` marks homework `ASSIGNED` or `COMPLETED` independently of its score. `hw filter` combines student, subject, due date and status criteria. `hw list INDEX all` includes overdue homework. [#68](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/68), [#88](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/88)
* **See work due soon:** `hw up [due/DAYS]` lists homework across students from today through the specified number of days, seven by default. Results include the student's index, score and status. [#69](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/69)
* **Edit the weekly lesson schedule safely:** `lesson edit LESSON_INDEX` can update a lesson's subject, weekday or time. Adding or editing a lesson checks the entire schedule, including students hidden by a search or filter, and reports clashes while allowing adjacent lessons. [#65](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/65), [#88](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/88), [#93](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/93)
* **Review the day at a glance:** A resizable sidebar shows weekly lessons and outstanding homework across the full roster. Overdue assigned work is highlighted, and student cards show upcoming and overdue counts. The display refreshes when the date changes. [#76](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/76)
* **Enter text containing prefix-like words:** Quoted values such as `t/"Speed in km/h"` keep their text intact. [#73](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/73)

The User Guide and in-app help now cover these commands. The Developer Guide adds and updates UML diagrams for student, homework, lesson and UI flows. [#83](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/83), [#85](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/85), [#88](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/88), [#90](https://github.com/AY2627S1-CS2103-F12-1/tp/pull/90)

## Getting started

1. Install Java 25 or later. On macOS, follow the [User Guide's Java setup instructions](https://ay2627s1-cs2103-f12-1.github.io/tp/UserGuide.html#quick-start).
2. Download `addressbook.jar` from this release and place it in a folder of your choice.
3. Open a terminal in that folder and run `java -jar addressbook.jar`.
4. Type `help` for the command reference, or start with `list`.

TutorFlow stores data locally in `data/tutorflow.json` relative to the folder where it is run. Back up that file before deleting data or editing it manually. See the [User Guide](https://ay2627s1-cs2103-f12-1.github.io/tp/UserGuide.html) for command formats and data-file rules.

## Current limitations

* This is an alpha version. More testing, documentation and interface polish are planned for v1.5.
* Lesson times must be on the same day; overnight lessons are not supported.
* Student, homework and lesson deletions cannot be undone. Back up the data file first if you may need to restore them.
* Existing AddressBook-Level3 contact files are not migrated into TutorFlow student records.
