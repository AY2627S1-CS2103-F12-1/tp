# TutorFlow v1.5 - Release candidate

TutorFlow v1.5 refines the [v1.4 alpha](https://github.com/AY2627S1-CS2103-F12-1/tp/releases/tag/v1.4) for public beta testing. Manage student and guardian contacts, weekly lessons, homework, marks and completion status through typed commands, with an at-a-glance view of your schedule.

## Changes since v1.4

* **Filter students by regular meeting day.** Combine `d/MONDAY` with optional level and subject criteria. Active
  criteria remain visible and results update after lesson changes.
* **Protect invalid saved data.** If TutorFlow cannot load valid records, it shows the full data-file path and recovery instructions, then stops before opening the roster. The original data file is preserved so you can restore a backup or correct it.
* **Distinguish students sharing a name.** Lesson listings, clash reports and add/edit/delete feedback include the student's phone number alongside their name.
* Lesson listing and homework filtering use singular feedback for one matching record.
* **Keep files beside the JAR.** Data, preferences and logs use the JAR's folder even when launched from another terminal directory.
* **View one student's lessons.** `lesson list STUDENT_INDEX` shows that displayed student's schedule while retaining the global lesson numbers used by editing and deletion. `lesson list` still shows the full schedule.
* Lesson-add errors identify missing prefixes and overflowing student indices. The guide and help examples work with the sample roster.
* **Updated guides and website.** The quick start explains Java 25 and a writable home folder. The Developer Guide's launch, sorting, recovery and release procedures match the application. The homepage and screenshot describe the implemented product.
* Gradle development launches enable assertions to check internal invariants.

## Download and run

1. Install Java 25 and verify it with `java -version`. macOS users should follow the [User Guide's setup instructions](https://ay2627s1-cs2103-f12-1.github.io/tp/UserGuide.html#quick-start).
1. Download the attached `addressbook.jar` to an empty writable folder.
1. Open a terminal, `cd` to that folder and run `java -jar "addressbook.jar"`.
1. Start with `help`, `list` or `lesson list`. See the [User Guide](https://ay2627s1-cs2103-f12-1.github.io/tp/UserGuide.html) for every command.

Keep the JAR in the same home folder: data is stored in `data/tutorflow.json` and preferences in `preferences.json` beside it. Back up the data file before editing or deleting records. The JSON structure is unchanged, but v1.5 validates saved records using its current rules. For example, two students with the same name and equivalent local/+65 phone numbers count as duplicates; resolve these in v1.4 before upgrading. If v1.5 rejects a file, it preserves the original and reports the reason. If v1.4 was launched from a different terminal folder, copy its data and preferences beside the JAR before starting v1.5, backing up both locations first.

## Current limitations

* Regular lessons repeat weekly on one weekday; overnight lessons are not supported.
* Every overlapping lesson is treated as a tutor clash. A simultaneous lesson shared by multiple students cannot be represented as a group lesson.
* Deletions cannot be undone. Keep a backup if you may need to restore records.
* Homework listing and upcoming commands include completed homework when its due date is in range. Use `homework filter status/ASSIGNED` to find assigned work; the sidebar shows assigned work independently of scores.
* AddressBook-Level3 contact files are not migrated into TutorFlow student records.
